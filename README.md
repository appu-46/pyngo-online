# pyngo-online

Online Bingo for 2-5 players, with rooms you join by code. A grown-up version of
[pyngo](https://github.com/appu-46/pyngo), a terminal Bingo game written in 2021.

- `shared/`: message types shared by the server and the client
- `server/`: Node + TypeScript WebSocket game server
- `client/`: React + Vite web app

See [docs/PROTOCOL.md](docs/PROTOCOL.md) for the rules, architecture and message flow.
